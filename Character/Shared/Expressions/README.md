# Expressions

18 ekspresi (grid 3x6) dalam 4 set: `profile_16x16`, `profile_16x32`, `profile_16x32_v2`, `profile_32x32`.

```
profile_<set>/profile_<set>_<ekspresi>.png   1 file = 1 ekspresi
sheets/                                      sheet PNG per set + label
source/expression_sheet_full.aseprite        file sumber
expressions.json                             daftar ekspresi + posisi di sheet
```

Path di `expressions.json` relatif terhadap folder `Shared/Expressions/`.
